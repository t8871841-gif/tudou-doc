# 汉唐中医 v1.11.18 发布说明

> 发布日期：2026-09-07
> 内部版本：1.11.18+10（Android versionCode=10）

## 一句话
八字 / 关煞 / 紫微三屏出生农历统一为「甲辰（2024）年正月初一」，农历按日历日正午取数，消除午夜跨日偏移。

## 新增（Added）
- 出生农历新增干支年 + 公历年标注：显示为 `甲辰（2024）年正月初一`。
- 新增农历展示回归测试 `test/lunar_birth_date_test.dart`。

## 改进（Changed/Improved）
- **三屏格式统一**（`lib/services/bazi_service.dart`、`lib/services/ziwei_engine.dart`）：八字屏、关煞屏、紫微屏出生农历统一为「干支年（公历年）年 + 农历月日名」。
- **紫微屏布局**（`lib/screens/ziwei_chart_screen.dart`）：「出生农历」「出生农历月」（标闰月）两行上移至「八字」行上方，四柱显示在农历下方。
- **农历取数口径**：统一按日历日正午（`12:00`）换算农历，规避真太阳时修正把午夜出生者农历回拨一天。

## 修复（Fixed）
- 紫微屏午夜出生农历偏移一天：2023-01-22 曾显示「壬寅（2023）年腊月三十」，正确应为「癸卯（2023）年正月初一」。
- 早子时分支农历与公历 +1 不同步：现同步改用次日正午取农历。
- 农历格式串缺字：`LunarDate.monthNameStr` 不含「月」、`dayName` 不含「日」，此前输出「甲辰（2024）年 五初五」，已补正为「甲辰（2024）年五月初五」。

## 测试验证
- `test/lunar_birth_date_test.dart`：三锚点断言（2024-02-10 → 甲辰（2024）年正月初一、2023-01-22 → 癸卯（2023）年正月初一、2024-06-10 → 甲辰（2024）年五月初五）+ 时辰无关性组（3 锚点 × 5 时辰 × 早晚子时开关）+ 紫微 `ZiweiChart.lunarText` 断言组，11/11 通过。
- `flutter analyze` 0 issue。
